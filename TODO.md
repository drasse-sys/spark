# Spark — videre ideer etter v5.3

## Høy verdi

- Synkroniser barneprofiler, undervisningslogg og ferdige økter via backend slik at samme barn kan bytte telefon uten å miste kontinuitet.
- Bygg et lite strukturert «mestringsminne» per begrep: dato, nivå av selvstendighet, vanlig feil og hva som hjalp. Bruk dette til relevant spaced retrieval senere — ikke generelle daglige quizer.
- En enkel foreldreside som viser parede enheter og lar én telefon tilbakekalles uten å logge ut alle.
- Test faktisk norsk stemmekvalitet på Olavs og lillebrors telefoner. Hvis systemstemmene fortsatt er for robotaktige, vurder valgfri Gemini TTS via backend.

## Etter praktisk bruk

- Følg med på om metakognitive spørsmål føles naturlige eller blir for mange.
- Se om Spark faktisk fader ut hjelp etter mestring i stedet for å fortsette med hint.
- Test om den sparsomme retrieval-praksisen gir gjenkalling uten å forlenge leksene unødvendig.
- Se om interessevariasjonen føles naturlig eller om personlige referanser bør være enda sjeldnere.
- Test kamera → avskrift → tekst-only videreføring på begge barnas typiske lekseark.
- Test «Ferdig med leksa» når Gemini er utilgjengelig.

## Bevisst ikke prioritert

- Poengtavler, streaks og tung gamification. Læring og mestring skal være hovedmotivasjonen.
- Automatisk karaktersetting.
- Analyse av barnets personlighet, diagnoser eller faste «læringstyper».
